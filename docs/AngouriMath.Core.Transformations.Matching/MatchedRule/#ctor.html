    Summary

    A rule whose right-hand side is code and wants the node it matched as well as
    the bindings.

    Remarks

    Not a convenience. A replacement that needs the whole expression — because it hands it
    to a helper that decides for itself whether to rewrite — otherwise has to rebuild it
    from the bindings, and a rebuilt node is a different object with none of the
    original's cached work    : its InnerSimplified, Evaled, Codomain and rate are all computed again, on every attempt, for every node of the tree.
     Measured on the limit of x * ln(x) / cos(x), which reaches
    RationalizeDenominator at every quotient it builds: rebuilding cost 4.0 s to
    5.2 s    , and a test with a thirty-second cap failed on two of the three CI platforms
    while passing locally. Handing the node over costs nothing and the rule keeps the
    caches it was given.
