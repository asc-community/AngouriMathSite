Summary

Steps with the tidying taken out and the repeats collapsed — the rewrites
that are worth reading. #28

Remarks

Two things are dropped, and neither is a judgement about importance. Sets that declare
IsNormalization are the engine straightening an expression
between real rewrites. And a rewrite that has already appeared is not shown again: the
simplifier explores several candidate forms and rewrites the same subexpression the same
way in each, so the raw list repeats itself many times over.
 On x^(-1)/(y/z) that is 270 recorded rewrites down to 5.
This is a set of rewrites, not a path. Each entry is a real rewrite that really
fired, on the subexpression it names — but Simplify(System.Int32) searches candidate
forms and keeps the best, so these come from several branches and some belong to
candidates that were discarded. Reading them in order does not walk from the input to
the answer, and a step's Before is a subexpression rather than
the whole expression at that moment. PathFrom(AngouriMath.Entity,AngouriMath.Entity) is the view
that does walk it, at the grain of whole expressions.
