Stringize

 Method with 2 overloads

  • Stringize

    Summary

    Converts an expression into a string. Works synonymically into ToString.

    Remarks

    A node whose Codomain is not the one its type carries by default is
    printed inside domain(inner, SET), which is the syntax the parser already has
    for it. Without that the annotation is dropped and the printed form reads back as a
    different expression — domain(sqrt(-1), RR) is NaN and
    sqrt(-1) is i, and the two used to print the same string.
    #1022

  • Stringize​(System.​Boolean)

    Summary

    Converts an expression into a string

    Parameter "parenthesesRequired"

    Whether to wrap with '(' and ')'

    Remarks

    A node that prints its codomain needs no brackets whatever its priority, because
    domain(...) is a function call and so already binds tighter than any operator
    around it.
