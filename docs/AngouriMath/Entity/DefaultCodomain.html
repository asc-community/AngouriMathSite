DefaultCodomain

 Property

Summary

The codomain a node of this type carries when nothing has narrowed it: the one that
parsing the node's own printed form, without a domain(...) around it, gives back.

Remarks

It is not Complex everywhere, which is why the printer cannot
assume a single default: a Variable and a Matrix are
Any, an Absf and an Interval are
Real, every boolean node is Boolean, and each
numeric literal takes the domain of its own type.
Stringize compares against this to decide whether to print the
annotation at all. A codomain equal to it is already what the bare text means, so
wrapping it would put domain(...) around every expression in the library; one
that differs is lost unless it is printed.
#1022 Abstract rather than defaulted, so that a node declaring a Codomain and
forgetting this one does not compile. The two are declared side by side in
Domains.Classes.cs and must name the same domain;
CodomainSurvivesPrintingTest.AFreshNodeCarriesItsDefaultCodomainAndPrintsNoAnnotation is the check that they do.
